QUICK GUIDE

Using MathsMate

Equations

Add an equation and type mathematics. Press Enter to create the next equation line.

Text boxes

Add a text box for explanations. Enter creates a new line. Start with - or 1. to continue a list automatically.

Move and resize

Drag the dotted handle to move an item. Drag its bottom-right corner to resize it.

Drawing

Choose Pen or Eraser, then draw using a mouse, laptop touchpad or touchscreen/stylus.

Save and export

Save board stores a named copy in this browser. Export PDF opens the print dialog; choose Save as PDF.

Saved boards are local to this browser and are not synced to another device.

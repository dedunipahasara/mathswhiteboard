How to Use MathsMate

1. Add Equations

Equation button එක click කර ගණිත සූත්‍ර type කරන්න. Whiteboard එකේ හිස් තැනක් click කරත් equation එකක් එකතු කරන්න පුළුවන්.

2. Mathematical Symbols

Symbol library එකෙන් අවශ්‍ය සංකේතය තෝරන්න. එය තෝරාගත් equation එකට එකතු වේ.

3. Add Notes

Text Note භාවිතයෙන් ගණිත ගැටලුවක පියවර, පැහැදිලි කිරීම් සහ පිළිතුරු ලියන්න.

4. Move and Resize

Object එකේ ඉහළ ඇති drag handle එකෙන් අවශ්‍ය තැනට ගෙන යන්න. පහළ දකුණු කෙළවරෙන් ප්‍රමාණය වෙනස් කරන්න.

5. Drawing Tools

Pen තෝරා mouse, touchpad හෝ stylus එකෙන් අඳින්න. Eraser මඟින් ඇඳි රේඛා මකා දමන්න.

6. Save Your Work

Save button එකෙන් පුවරුව නමක් සමඟ සුරකින්න. Open button එකෙන් කලින් සුරැකි පුවරු නැවත ලබාගන්න.

7. Export as PDF

PDF button එක click කර browser print window එක විවෘත කරන්න. Destination ලෙස Save as PDF තෝරන්න.

Note: සුරැකි පුවරු මෙම browser එකේ සහ device එකේ local storage තුළ තබා ගනී. වෙනත් device එකක ඒවා ස්වයංක්‍රීයව ලබාගත නොහැක.

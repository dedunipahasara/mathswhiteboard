Keyboard: ලියන විට laptop keyboard එක භාවිතා කරන්න. MathLive editor එක fractions, roots, powers, trig සහ අනෙකුත් සංකේත හඳුනාගනී.

සටහන්: “සටහනක්” click කර සාමාන්‍ය විස්තර type කරන්න.

Move: Equation එකේ පිටත border එක drag කර වෙනත් තැනකට ගෙන යන්න. Formula එක ඇතුළේ click කළොත් edit mode එකට යයි.

Save: සටහන් මේ browser එකේ save වේ. PNG download කිරීමෙන් image එකක් ලබාගන්න පුළුවන්.

MathLive සූත්‍ර editor එක load වීමට internet connection එකක් අවශ්‍යයි. Saved data එක මේ browser/device එකට සීමා වේ.
